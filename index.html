Примеры запросов

О данных

На Windows отправляются только сообщение и ограниченная сводка задач, целей, смен, тренировок и прогресса. Фотографии, записи дневников и полный архив данных не передаются.

Между Mac и Windows используется HTTP в домашней сети. Ответы AI могут содержать ошибки — сверяй важные детали.

Рабочий график

Дневная → дневная → выходной → выходной → ночная → ночная → восстановление → выходной. Затем цикл повторяется.

Дневные: 08:00–20:00. Ночные: 20:00–08:00 следующего дня. Смена даты начала пересчитывает цикл; ручные исключения сохраняются.

Исключение для отдельного дня

Настройки профиля

Данные сохраняются в локальном хранилище браузера на этом устройстве. Это не облачная синхронизация.
Установить LIFE OS

На iPhone: Safari → Поделиться → На экран «Домой». После установки проверь прогресс: Safari и установленное приложение могут иметь отдельные данные. Сначала сделай полную копию.

Резервная копия

Закрой другие вкладки LIFE OS перед экспортом или восстановлением. Полная копия содержит личные данные и фотографии; храни её в безопасном месте.

Полная копия: JSON и фото, SHA-256, до 128 МБ. Восстановление заменяет все данные и фотографии.

Старый формат без фотографий

Периодически экспортируй данные, чтобы не потерять прогресс при очистке браузера.

Состояние синхронизации

Локальные данные · Синхронизация не подключена

Как работают данные

Данные остаются в хранилище этого браузера. Между устройствами синхронизация не включена; для переноса используй полную резервную копию.

Облачное подключение

Не подключено

Проверка входа не отправляет задачи, прогресс или фотографии. Синхронизация ещё отключена. Auth-сессия восстанавливается в этой вкладке после перезагрузки. После закрытия вкладки может потребоваться новый вход.

О приложении

LIFE OS — локальное приложение для личных целей, задач и прогресса.

Установка и обновление

На iPhone открой LIFE OS в Safari, нажми «Поделиться» и выбери «На экран “Домой”». После появления сообщения об обновлении сохрани изменения, закрой открытые вкладки LIFE OS и запусти приложение снова.

Проверенная полная копия

Все данные и фотографии в этом браузере будут заменены. Закрой другие вкладки LIFE OS. Для сохранения текущего прогресса сначала экспортируй его.

История фактических результатов
История адаптации

Перенести занятие

Занятые даты и завершённые занятия не переносятся. Отметки сохраняются.

Экзамен

Статус рассчитывается по всем нормативам. Предыдущие попытки сохраняются.

Новое измерение

Укажи хотя бы один показатель. На одну дату — одна запись. Фотографии сохраняются отдельно по своей дате.

Фотографии прогресса

Любой ракурс необязателен. JPEG, PNG, WebP до 30 МБ; перед сохранением — сжатие до 1600 пикселей и удаление метаданных. Фото сохраняются только в браузере.

Восстановление фотоархива

Числовые измерения восстанавливаются через обычный импорт LIFE OS.

Управление программой

Связанная цель, этап и другие задания сохраняются. Архивирование сохраняет все занятия в календаре и их историю.

Изменение нагрузки

Меняется только один показатель. Выбери будущие занятия без результатов. Определение программы, даты, XP и выполненные занятия сохраняются.
